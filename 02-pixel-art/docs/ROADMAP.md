# Roadmap

- [ ] **Edge-aware downscaling.** Keep 1-pixel outlines (detect strong edges at full
  resolution and darken the cells they cross), the main difference from hand-made pixel art.
- [ ] **CIEDE2000** for matching and evaluation, and a check whether it changes any
  decision in RESULTS.md.
- [ ] **A user study** (A/B votes in the app's feedback box) to test whether ΔE rankings
  match what people prefer.
- [ ] **More palettes** (NES, CGA, user-defined) and palette export (.hex, .gpl).
- [ ] **Animated GIF input**, frame by frame with one shared palette.

# Benchmark results

_Generated by `python -m experiments.run`; do not edit by hand._

100 images per test set (random, seed 0), longer side scaled to ≤ 1024 px. Mean over images. Speed is measured separately (see the last section): timings taken during this run were too noisy to report. CPU: Intel64 Family 6 Model 186 Stepping 2, GenuineIntel, onnxruntime 1.31.0, OpenCV 5.0.0.

IoU: mask overlap (higher is better). MAE: mean absolute error of the soft matte (lower is better). Boundary F: how well the outline matches within ~0.75% of the image diagonal (higher is better).
